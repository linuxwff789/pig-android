## 「回到底部」气泡可以由 UI pack 配色了

之前这个气泡写死了 `primary` / `onPrimary` 和 6dp 投影，pack 改不了。现在
`layout/chat.json` 的 `chat.chrome` 支持：

```json
"chrome": {
  "fabBackground": "surfaceVariant",
  "fabBackgroundAlpha": 0.86,
  "fabTint": "onSurface",
  "fabTintAlpha": 1.0
}
```

- `fabBackground` / `fabTint` 用主题 token（`primary`、`secondary`、`surface`、
  `onSurface`、`error`、`none` 等），透明度分别由 `fabBackgroundAlpha` /
  `fabTintAlpha` 控制（0–1）；
- 投影高度改用 `theme/colors.json` 里原本就有的 `fabElevation`，不再是写死的 6dp；
- 改完保存即热更新，不用重装 App。

示例（半透明青灰胶囊、不透明文字）：

```json
"chrome": {
  "fabBackground": "surfaceVariant",
  "fabBackgroundAlpha": 0.8,
  "fabTint": "secondary"
}
```

## 升级

1. 装 `app-release.apk`（1.1.48，旧版不认这四个键）；
2. Termux 里重跑安装命令（relay 行为不变）；
3. 编辑 `~/.pig/android-ui/layout/chat.json`，保存后 App 一秒内生效。
