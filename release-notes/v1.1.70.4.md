## 收尾：审查清单里剩下的项（App + relay）

### 会话
- 新会话创建期间修改的思考档位 / 自动压缩 / 自动重试 / 队列模式不再发给即将被替换的
  旧运行时，等 `new_session` 确认后按顺序补发；思考档位也记在新会话使用的模型名下。
- 连续点「新会话」不会再把已经输入、等待发送的 prompt 清掉。
- 重连后历史窗口重置回第一页，不再每次都重新拉 2000 条。

### UI pack / 窗口
- 表单值按 pack hash 隔离，切 pack 后同名字段不会带上一个 pack 的值。
- 旋转/折叠后窗口位置会在渲染时 clamp，不会再跑到屏幕外拖不回来。
- `dismissible:false` 的窗口不能被 Back / 下滑关闭（pack 自己的 `builtin:close` 仍可关）；
  关闭记录持久化，重启后不会重新弹出。
- pack 图片按 1024px 采样解码并限制缓存数量；表格行数、表头、select 选项和单元格长度都有上限。
- 只读 / 待发送 banner 不再由 pack 控制，安全提示不会被主题藏掉。
- pack 的字体解码、SHA-256 和落盘移出主线程；通知文件读写也移到 IO。
- Markdown 远程图片禁止 loopback/内网/链路本地地址，重定向只允许同主机且不降级到 http；
  失败缓存 5 分钟后可重试，并发限制为 4。

### relay / 备份
- restore 解压拒绝经过 symlink 写出 `~/.pig`；备份时文件在 walk 后缩小会用 0 补齐，
  不再让整个备份失败。
- 内置扩展先写 `.embedded-hash` 再写文件，中途被杀不会把目录误判成用户目录；
  plan/pigkit 的同步和 hash 都支持子目录，过期子目录会被清掉。
- 备份完成帧带上 `includes`（models/providers/settings/auth），App 的完成提示据此显示
  「含模型配置 / 未发现模型配置」。
- `!command` 超时已在上轮修好；本轮补上 relay 的 `go test -race`。

### WebDAV / 后台
- 定时备份用 foreground service（dataSync）跑，慢上传不再被 WorkManager 的 10 分钟窗口取消。
- `http://` 需要显式勾选「允许明文连接」（已有配置自动放行，避免升级后备份突然停摆）。
- KeepAlive 的 CPU wake lock 改为 30 分钟超时 + 29 分钟续期，不会无限持锁。
- relay 启动参数里的 token 也做了 shell quote。

### 工程
- release `versionCode` 改为按四段版本号生成（`1.1.70.4 → 101070004`），不再用
  `git rev-list --count`（回退分支/同 commit 双 tag 会撞号）。
- 新增 `scripts/check-embedded-go.sh`（内嵌扩展语法检查）、`scripts/version-code.sh`，
  CI 增加 `go test -race` 和内嵌扩展语法检查。
- 新增 PlanWidget 解析单测；plan 扩展在本地有 SDK 缓存时跑完整测试，CI 仍跑纯策略测试。
- 内嵌 plan README 同步中文版，并修掉解压后失效的相对链接；清理本地旧 APK 产物。

装 `app-release.apk` 后在 App 里重启 relay（或重开 App）生效。
