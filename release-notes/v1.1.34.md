## 备份、恢复与卸载，全都能在 App 里点

`~/.pig` 在 Termux 的私有目录里，App 一直碰不到它 —— 想换台设备、想重装、想清空，
都只能去 Termux 里敲命令。这一版让 relay 当文件服务器：备份以 gzip tar 分块从回环
socket 流出来（协议见 `docs/protocol.md`），导入原路送回去。

设置 → **备份与维护**：

- **导出备份** → `Download/Pig/pig-backup-<时间>.tar.gz`（Android 10+ 走 MediaStore，
  不需要权限；更老的系统弹系统保存框）。可勾选：
  - **会话记录**（默认开，占体积大头，几十 MB）；
  - **UI pack**（默认开）。
  密钥（`auth.json`、`models.json`、`custom-endpoints.json`）、`settings.json`、扩展
  和 `~/.pig/state` **始终包含**，所以备份里是**明文密钥** —— 对话框会先明说。缓存、
  崩溃输出、日志、符号链接不打包。进度显示已传字节。
- **导入备份** → 选 `.tar.gz` 并确认一次。relay 先校验大小和 SHA-256，把当前数据
  自动完整备份到 `~/.pig/backups/pig-auto-before-restore-*.tar.gz`，然后合并解压
  （同名覆盖，归档里没有的会话保留）。只接受 `.pig/` 下的条目，路径穿越、符号链接、
  设备文件一律忽略。之后 relay 停掉所有 pig 进程，App 自动重连 —— 恢复的模型、密钥、
  设置和 UI pack 直接生效。
- **卸载 pig 与 pig-relay** → 停进程、删 `$PREFIX/bin/pig`、`pig-relay`、旧
  `pig-relay.*` 副本和安装回执。可选「同时删除 ~/.pig 数据」，**默认关闭**；不勾选时
  之后重跑安装命令即可原样恢复。

## 模型供应商改成 App 原生页面（可以挑模型了）

以前「加供应商」是 `provider-ui` 扩展往 UI pack 里写一个 `windows/providers.json`，
表单和选择控件都受 pack 影响；刷新模型后也没有一个选择窗可以挑要启用哪些模型。

现在设置 → **模型供应商** 是 App 内置页面，UI pack 的 `nav.json` 只保留入口
（`window: native:providers`）：

- 列表直接读 `~/.pig/agent/custom-endpoints.json`：地址、API 类型、模型数、有没有
  保存 Key、自动还是手动；`models.json` 里的供应商只读展示。
- 新增/编辑写同一个文件（保留 `headers`、`oauth`、`defaults` 等表单外字段），
  API Key 只写不读——留空就是保持原 Key，另有「清除 Key」。
- **刷新模型列表** 由 relay 带正确的鉴权头去请求 `{baseUrl}/models`，成功后弹出
  **原生选择窗**：可搜索、勾选、全选/清空，显示上下文大小。选中的子集写成显式
  `models` 数组，完整列表留在 cache 里，下次打开选择窗不用再联网。
- 保存/删除后重启 pig（同一会话文件），随后自动刷新 `/model` 列表。
- `provider-ui` 扩展保留 CLI 命令（`/provider-ui`、`/providerui.*`），但不再生成
  window JSON；旧安装里的 `windows/providers.json` 不再影响页面。

relay 新增 `relay_providers` / `relay_provider_save` / `relay_provider_delete` /
`relay_provider_models`，握手 `features` 增加 `providers`。

## relay 协议

- `relay_hello` 新增 `version` 和 `features: ["backup","restore"]`，App 据此启用按钮；
  旧 relay 会看到「需要新版 relay」的提示，而不是 `unknown relay frame`。
- 新帧：`relay_backup` / `relay_backup_cancel` / `relay_restore_begin` /
  `relay_restore_chunk` / `relay_restore_end`。归档上限 1 GiB、chunk 48 KiB、同一时间
  只允许一个传输。
- 新增 `relay/backup_test.go`：归档往返、跳过会话、路径穿越拒绝、chunk 拆分与
  checksum；另用一个假 HOME 跑过导出 → 修改归档 → 导入 → 校验失败 / 取消的完整链路。

## 升级

1. 装 `app-release.apk`（1.1.34）；
2. Termux 里重跑安装命令升级 `pig-relay`（不带 tag 也会解析 latest 并升级）；
3. App → 设置 → 重启 relay。备份按钮需要 1.1.34 的 relay。
