## v1.1.71.26：自定义供应商的 key 同步进 auth.json

上一版把图片能力修正放进了 `custom-endpoints.json`，但漏了一条路径：App 切换模型时，pig 的 `set_model` 和图片预检走的是 `auth.json`，而不是扩展注册的 provider。所以全新安装（或删掉 auth 里的条目后）第一次切到自定义供应商，会报：

```
No API key found for eu.
```

现在 relay 会在两处自动同步：

- **启动时**：读取 `custom-endpoints.json`，把每个带 `apiKey` 的供应商写入 `auth.json`（`type: "api_key"`）；已有的凭据（`deepseek`、`opencode-go` 等）保持不动；
- **保存/删除供应商时**：新增的 key 立即写入，删除的供应商同时清理它的条目。

`$ENV` 引用会在同步时展开，`!command` 仍按原有语义取值（有 10 秒超时）。同步是原子写且权限 0600，不会产生半截文件。

这样新安装只需要配置 `custom-endpoints.json`：key 自动出现在 `auth.json`，切模型、发图都不会再报 `No API key found`。
