## WebDAV 备份（含定时上传）

设置 → 备份与维护 → **WebDAV 备份**。上传的是和「导出备份」同一份归档（会话、设置、
密钥、扩展、UI pack），支持任何 Basic 认证的 WebDAV：Nextcloud、Alist、群晖、
`rclone serve webdav` 都行。

- **服务器地址 / 用户名 / 密码 / 远程目录**：目录不存在时首次上传自动 `MKCOL` 创建，
  地址可直接写到用户目录（如 `.../remote.php/dav/files/me`）。
- **保留 N 份**：每次上传后删掉该目录里超出的旧 `pig-backup-*.tar.gz`。
- **定时备份**：关闭 / 每 6 小时 / 每 12 小时 / 每天 / 每 3 天 / 每周。用 WorkManager
  周期任务（要求联网），重启手机/App 都不会丢；后台任务自己连 relay，没在跑会拉起，
  执行期间前台 App 会短暂重连一次。
- **测试连接**：`PROPFIND`，目录缺失时会 `MKCOL`；
  **立即备份**：打包并上传一次；
  **远端备份**：列出归档（时间 + 大小），每条可「恢复」——恢复会下载到 App 缓存，
  再走原有恢复流程（relay 先备份现有 `~/.pig`，再解压，最后重连）。

安全：密码存在 App 私有设置（未加密），归档本身含明文 API key —— 请用 HTTPS 并限制
该目录的访问权限。

## 升级

1. 装 `app-release.apk`（1.1.54）；
2. Termux 里重跑安装命令；
3. 设置 → 备份与维护 → WebDAV 备份，填地址后先「测试连接」，再保存。
