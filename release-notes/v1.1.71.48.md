## v1.1.71.48：思考命中能停在眼前，高亮更清楚

**「思考定位不到」其实是滚过头了**
日志显示搜索已经找到了正确的那一行，但当这一行比屏幕还高时，「居中」会把行首的思考块顶出屏幕，看起来就像没跳过去。

- 命中思考时改为**行顶对齐**：跳过去的画面从思考块开始。
- 思考块展开/收起改变高度后会再次对齐，不会又跑掉。
- 正文、工具命中的居中行为不变。

**高亮更醒目**
- 思考卡本身有底色，之前的半透明关键词底几乎看不出来。
- 现在关键词用**实底主色 + 反色文字 + 加粗**，在任何底色上都能一眼看到。
- Markdown 正文、代码块、候选列表里的命中片段统一使用同一套高亮。

只装 APK 即可，relay 不需要更新。
