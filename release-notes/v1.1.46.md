## 项目里只保留一套 UI pack

之前 relay 会往 `~/.pig/android-ui` 种子一份 `examples/ui-pack-compact`，而 APK 的
`assets/ui-packs/compact` 又内置了同一套，于是「UI pack 管理」里出现两行一模一样
的 pack。

- 只保留 `examples/ui-pack-compact`（relay 内嵌并种子）这一套；
- APK **不再内置任何 pack**（`app/src/main/assets/ui-packs` 已删除），所以管理器
  只有 relay 那一行，不会再出现两套相同外观；
- 首次启动在 relay 推送之前先显示 App 默认外观，推送到达后接管；
- 内置 pack 的机制仍保留：自定义构建把 pack 放到 `assets/ui-packs/<name>/` 依旧会
  以 `builtin:<name>` 列出；
- 删除 `scripts/sync-bundled-packs.sh` 及 release CI 里的对应步骤；
- `tools/fresh-device-sim/sim.sh pack` 改为校验 `relay/embedded/ui`，并断言 APK 里
  没有内置 pack。

## 升级

1. 装 `app-release.apk`（1.1.46）；App 里如果之前 pin 过某个 pack，去「UI pack 管理」
   点一下 relay 那一行，之后外观就只由 `~/.pig/android-ui` 驱动；
2. Termux 里重跑安装命令（relay 1.1.46 的种子包回到 compact）；
3. App → 设置 → 重启 relay。
