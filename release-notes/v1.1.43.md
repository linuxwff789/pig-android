## 修好「模型供应商」入口从 UI pack 里消失 / nav.json 报错

`nav.json` 的 window 校验只允许 `[a-z0-9._-]`，而供应商入口现在写的是：

```json
{"id":"providers","window":"native:providers","placement":"settings"}
```

冒号被当成非法字符，整项被丢弃，同时 UI pack 报：

```
nav.json 第 1 项 window 无效
```

于是第一个 pack（relay 推送的那个）里就没有「模型供应商」，设置里还会显示这条
pack 警告。

- 校验允许冒号：`native:<id>` 是 App 内置窗口的合法写法；
- 内置 compact pack 的 `nav.json` 也改成 `native:providers`；
- 旧 pack 里只写 `window: "providers"` 的仍然兼容（App 直接打开原生供应商页）。

现在供应商入口会重新出现在 pack 的导航里，`nav.json` 的警告也消失。设置 → 连接
里的固定入口和首次配置卡片不受影响，仍然可用。

## 升级

1. 装 `app-release.apk`（1.1.43）；
2. Termux 里重跑安装命令（relay 行为不变）；
3. App → 设置 → 重启 relay。
