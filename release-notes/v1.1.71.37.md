## v1.1.71.37：修好搜索跳转，候选列表可折叠

**跳转为什么一直不生效**
- relay 从会话文件读历史时，只把消息本体返回给 App，把外层记录的「消息 id」和「时间戳」丢掉了。App 用来定位的两个键都是空的，所以无论点哪一条都跳不过去。
- 顺带修了另一个问题：定位逻辑在只有时间戳、没有 id 时会直接放弃，导致旧版 relay 永远无法跳转。

现在 relay 会把消息 id 和时间戳一起返回，App 用 id 匹配，时间戳作为兜底。**注意：这项修复在 relay 侧，必须重启 relay 才会生效。**

**候选列表不再占满屏幕**
- 搜索条下方的候选列表固定 180 dp 高度，内部滚动。
- 点计数旁边的 ▴ / ▾ 可以折叠或展开候选列表。命中几十条时也能让聊天区保持可见。

**其他**
- 折叠时只保留搜索框和计数，按 ↑ ↓ 仍可在命中之间跳转（跳转时会自动展开列表）。
- 搜索条打开期间的所有命中高亮、折叠卡片/工具组/思考块自动展开，仍按上一版行为。

relay 与 APK 都需要更新。
