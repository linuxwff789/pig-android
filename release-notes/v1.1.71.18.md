## v1.1.71.18：真正的“半截回复”是跟随被关掉了

线索来自你这次的操作：**点一下“回到底部”内容就回来了**。内容一直都在，只是列表没有跟着往下走。

查下来是跟随开关被一次**点按**关掉的：

```kotlin
// MessageRow / ToolGroupCard 的 onUserRead
onUserRead = { autoScroll = false }
```

`onUserRead` 在点开一张工具卡、或展开一个工具分组时触发（你在一轮长回答中途想看看它在干什么，点了一下），于是“自动跟随”被永久关掉——直到你手动点“回到底部”。回答本身还在流式写入，只是长在视口下面，看着就像停在半句、Markdown 没解析（流式期间本来就是原文）。点按不是滚动，不该被当成“读者走开了”。

这一版：

- **点开工具卡/分组不再关掉跟随**，只有真正的拖动才暂停；点“回到底部”恢复。
- 加两行诊断：`[scroll] follow off (drag)`（拖动暂停）与 `[scroll] follow on (pill)`（点胶囊恢复），量级是一次交互一行。

前几版（15/16/17）的看门狗、收养收尾帧、relay 补发仍然是有效的兜底：真的丢帧时会自愈，而不是留个半截气泡。
