## 供应商入口不再依赖 UI pack

「模型供应商」原来只在 UI pack 的 `nav.json` 里（`window: native:providers`）。
如果用户用了本地 pack、nav 被旧备份覆盖，或者还没有任何 UI pack 推送，入口就会消失。

- 设置 → 连接 里现在有**固定的「模型供应商」一行**（管理按钮），不依赖 UI pack，
  连上 relay 就能打开；首次启动卡片的「添加供应商」也仍然在。
- relay 在**没有 pig 进程**时也会回答 `get_available_models` / `get_available_thinking_levels`
  （空列表），所以全新后端不启动 pig 也能让 App 知道“当前 0 个模型”，
  首次配置卡片会正常出现，而不是什么都没有。
- 空后端仍然不是错误：卡片 + 设置入口二选一，添加供应商或导入备份即可。

## 升级

1. 装 `app-release.apk`（1.1.40）；
2. Termux 里重跑安装命令（或让 App 的「更新 relay」处理）；
3. App → 设置 → 重启 relay。
