## 修好「刷新模型列表」：Android 上没有 `/etc/resolv.conf`

relay 是 `CGO_ENABLED=0` 编译的，Go 自带解析器只读 `/etc/resolv.conf`；而 Android
没有这个文件（Termux 的放在 `$PREFIX/etc` 下），于是它回退到 `[::1]:53`，刷新时报：

```
dial tcp: lookup linuxwff.eu.cc on [::1]:53: read udp ...: connection refused
```

pig 本体是带 cgo 编译的，走 libc/netd 解析，所以聊天正常、只有 relay 的刷新坏掉。

现在 relay 自己解析域名，顺序是：

1. `PIG_DNS`（如 `PIG_DNS="1.1.1.1 8.8.8.8"`，可覆盖）
2. Termux 的 `$PREFIX/etc/resolv.conf`
3. 公共 DNS：`8.8.8.8` / `1.1.1.1` / `223.5.5.5`

解析出的地址用于建连，TLS 仍然按原域名校验（不受影响）。保存供应商时的自动抓取
也用同一个客户端，所以那条路径一起修好了。

## 升级

1. 装 `app-release.apk`（1.1.52）；
2. Termux 里重跑安装命令；
3. **设置 → 重启 relay**（新二进制才会生效，旧进程仍是坏的那份）；
4. 再点「刷新」，应该能列出模型。
