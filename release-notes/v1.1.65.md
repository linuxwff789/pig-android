## 回答你的问题：会下到正确的版本

拆成三处看（都已核对/修好）：

1. **App 自己的「检查更新」** —— 读 `releases.atom`，这个 feed **包含预览版**
   （实测第一条就是 v1.1.64）。点「打开」跳的是那条 release 的页面，里面的
   `app-release.apk` 就是该预览版本身，不会跳到旧版本。
2. **「复制 Termux 更新命令」**（以及 debug 构建用的安装脚本）—— 之前指向
   `/releases/latest/download/install-termux.sh`，那是**最后一个正式版**的脚本（现在停在 v1.1.63），
   等于把后端钉在旧 tag 上。现在改成直接取仓库里的脚本：
   ```
   curl -fsSL https://raw.githubusercontent.com/linuxwff789/pig-android/main/scripts/install-termux.sh | sh
   ```
   这个脚本自己会解析**最新 release（含预览版）**。
3. **App 内一键安装（设置里那条长命令）** —— 仍然用**本 App 自己的 tag** 取脚本
   （`releases/download/v1.1.65/install-termux.sh`，jsDelivr `@v1.1.65` 兜底），
   安装脚本被钉到同一版本，App 和 relay 版本一致。

顺带核对了资产：`v1.1.64` 那个 release 里的 `install-termux.sh` 已经带新逻辑
（`newest release is v…` + `per_page=1`），所以现在从任何入口跑都会拿到最新的预览版。

这个版本只有这一处修正，装上 `app-release.apk`（1.1.65）即可；relay 无改动。
