## v1.1.71.25：模型能力覆盖 + 图片显示更大

### 修正网关返回的错误能力

有些中转网关把支持图片的模型标成 `input: ["text"]`（例如 `wb2api/cn:deepseek-v4.1-flash`），pig 会据此把图片从请求里过滤掉，模型就"看不到图"。

`custom-endpoints.json` 的 provider 现在支持 `modelOverrides`，随 provider 配置一起保存/备份：

```json
{
  "providers": {
    "eu": {
      "modelOverrides": {
        "wb2api/cn:deepseek-v4.1-flash": { "input": ["text", "image"] }
      }
    }
  }
}
```

扩展注册模型时会把 overrides 合并进模型对象，因此全新安装只配置 `custom-endpoints.json` 也能生效，不再依赖 `models.json` 的覆盖（两者同时存在也兼容）。

### 图片按气泡宽度显示

会话里的图片现在撑满气泡宽度（之前保持原始宽度，宽截图会缩成小缩略图），高度上限也提高了：普通消息 360 dp、用户气泡 380 dp、工具卡片 320 dp。竖长图仍可点开全屏查看。
