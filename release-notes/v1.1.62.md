## 关于「删了会话再切换就报错」

先说清楚：**我看不到你手机上的 App 日志**（App 私有目录，Termux 没有 root 读不了），
所以之前那个 toast 一闪而过，我这边什么都没有。这次先让它可以被看见。

### 这次改了什么

- **每条 toast 都会写进 App 日志**（`[ui] toast: ...`），一闪而过的提示之后也能查到；
  `relay_session_error` 也会记一条 `[session] relay_session_error: ...`。
- **修了一个真实 bug**：relay 里「删除的正是当前激活的那个会话」时，`activePath` 没有清掉，
  下次 `get_state` / 启动 pig 时会指向一个**已经不存在的会话文件**。现在删除时会清空。
- **错误弹窗收窄**：以前任何 `relay_error` 都会弹「Termux 后端还没准备好」，很误导；
  现在只有真的离线 / 安装中 / 起不来 pig 才弹，其它错误只显示顶部横幅。
- `relay_session_error`（删除/重命名被拒）会顺带刷新会话列表，不会留一行幽灵会话。

### 请你这样复现一次

1. 装 `app-release.apk`（1.1.62），relay 也会一起更新（这次 relay 也改了）；
2. 删几个会话，再切到已有会话，让那个 toast 再出现一次；
3. 设置 → 日志 → **导出**（会存到 `Download/Pig/pig-log-*.txt`）；
4. 回我一句「导出好了」。

我直接读那个文件，就能看到 toast 的原文和前后几帧，不用你再抄。
