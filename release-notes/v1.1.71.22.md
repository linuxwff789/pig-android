## v1.1.71.22：审计修复与热路径优化

这一版来自一次完整代码审计，集中在「配置/命令的信任边界」「重连时的会话归属」和大历史下的渲染开销。

### 安全与正确性

- **provider 草稿不再执行命令**：`apiKey` 以 `!` 开头时只在 `custom-endpoints.json`（用户自己写在 Termux 侧）里保留 shell 语义；App 发来的未保存草稿按字面量使用。`!command` 输出上限 64 KiB。
- **重连不会串会话**：`relay_hello` 不再无条件丢掉「新会话正在创建」的状态。`new_session` 帧若丢在断线里，会重发并等 `get_state` 确认新 runtime 再发排队的 prompt 和思考档位。
- **后台不再静默掉线**：保持后台时 pig 退出会立即重连，而不是等下一次回到前台。
- **设置写入串行化**：扩展启停/卸载与设置页、内置扩展安装器共用一把锁，不再互相覆盖。
- **pig 退出不再误报**：先读完 stdout/stderr 再 `Wait`，不再出现假的 `pig frame too large`。
- **历史请求失败会重试**：`get_messages` 失败按 500/1000/1500 ms 重试三次，被更新的请求替换则放弃。
- 表单 `select` 提交值与界面显示一致；`buildHistory` 的 item id 带下标（同毫秒消息不再撞 key）。
- Markdown 围栏按 CommonMark 闭合，```` 包 ``` 不再被截断；app-ui 表格短行补齐列宽。

### 性能

- **历史**：`mergeHistory` 先找公共后缀（append-only 直接返回切片），非对齐部分用定长指纹去重；`clipHistory` 增加 8 MiB 字节预算（一条截图可达 2 MiB）。
- **会话抽屉**：列表元数据按 path+size+mtime 缓存，不再每次读几十 MB。
- **流式渲染**：`messages` 从 `AppUiState` 拆成独立 state（50 ms 的更新不再让整屏组合失效）；列表项按消息实例复用；`ChatMsg` 标 `@Immutable`；表格 AST 遍历与对齐解析加 `remember`。
- **内存**：pack 图缓存改为 40 MiB 字节上限（原来 48 张 1024 px 位图可达约 192 MB）；诊断日志按字符预算并批量落盘。
- **relay**：`streamText` 改用 `strings.Builder` 并设 1 MiB 上限；`pig install` 有 5 分钟超时；`/models` 刷新限制 2 并发。
