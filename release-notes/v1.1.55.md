## WebDAV：支持明文 HTTP 与自签名证书，报错看得懂

自建 NAS 常见两种情况会让「测试连接」直接失败：

1. **`http://` 明文地址**：App 原来只允许本机回环走明文，其他 http 一律被系统拦截，
   报 `Cleartext HTTP traffic to ... not permitted`；
2. **自签名证书**：`https://` 但证书不被系统信任，报 TLS 握手失败。

现在：

- 允许明文 HTTP（地址以 `http://` 开头时，对话框里会红字提醒「账号密码和备份都会裸传」，
  能用 https 还是用 https）；
- 新增 **忽略证书错误** 开关：只对当前这台服务器跳过证书与域名校验，默认关闭；
- 常见失败都翻译成人话：明文被拦、TLS/证书、域名解析失败、连接超时、连不上服务器，
  并附上原始信息。

排查顺序建议：

1. 地址写到「用户根目录」，例如 Nextcloud 是
   `https://host/remote.php/dav/files/用户名`，不要只写域名；
2. Nextcloud 开了两步验证时，密码要用「应用密码」；
3. 401/403 = 账号密码或权限问题（目录要可写）；404 = 路径不对（首次上传会自动建目录）；
4. 自签名证书 → 打开「忽略证书错误」再测试；
5. 群晖/威联通需要先在管理界面启用 WebDAV 服务并确认端口。

## 升级

1. 装 `app-release.apk`（1.1.55）；
2. Termux 里重跑安装命令；
3. 设置 → 备份与维护 → WebDAV 备份 → 测试连接。
