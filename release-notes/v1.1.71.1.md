## v1.1.71.1：UI pack 可视化编辑器

**设置 → UI pack 管理 → 编辑当前 pack** 现在会打开一个可视化编辑器，不用再手改 JSON。

- 读取当前生效的 pack（relay / 内置 / 导入均可），把 `theme/colors.json`、
  `theme/typography.json`、`components.json`、`layout/chat.json` 里约 300 个标量键
  变成控件：取色器（HSV + 透明度 + hex）、颜色 token 下拉、滑杆 + 精确输入、开关、
  枚举、字体。
- 搜索框支持中文标签 / 键名 / 说明；「已改」只显示动过的键；每个键可单独重置，
  开启「显示说明」会展开用途。
- **实时预览**默认开启：改动约 200 ms 内套用到界面；关闭后只改草稿。
- 结构型字段（`header.body` / `header.rows` / `chat.toolCard.byTool` /
  `dataSources` / `bindings` / `actions` / `strings.json` / `icons.json` /
  `nav.json` / `skins.json` / `windows/*.json`）用原始 JSON 编辑器，带语法校验。
- **保存**会新建一个本地 pack 并切换过去，原 pack 不受影响；**导出**生成 ZIP，
  可以直接放进 `~/.pig/android-ui/` 交给 relay。

当前是预览版；装 `app-release.apk` 后直接在 App 里打开编辑器即可。
