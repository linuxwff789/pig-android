## 工具卡：可以限宽，也能按工具类型配色

**宽度上限**（`chat.toolCard.maxWidth`，单位 dp，0 = 铺满）：

```json
"chat": { "toolCard": { "maxWidth": 420 } }
```

单张卡和工具组都生效，始终保持左对齐。

**按工具类型配色**（`chat.toolCard.byTool`）：

```json
"chat": {
  "toolCard": {
    "byTool": {
      "bash":  { "iconTint": "success", "iconBackground": "success" },
      "edit":  { "iconTint": "warning", "iconBackground": "warning" },
      "write": { "iconTint": "primary", "iconBackground": "primary" },
      "read":  { "iconTint": "secondary", "iconBackground": "secondary" },
      "codegraph*": { "iconTint": "warning", "titleColor": "warning" }
    }
  }
}
```

- 键是小写工具名；`*` 结尾表示前缀匹配，精确匹配优先；
- 每项可设 `iconTint` / `iconBackground` / `titleColor` / `borderColor`，未设的继承卡片默认；
- 工具组表头按组内第一个工具取色，出错时错误描边优先。

## 插队/排队消息：点一下就能取回来改

「待发送消息」里点任意一行，会把这条消息**移出队列并填回输入框**，改完重新发即可。

- 已被 pig 消费（真正进入回合）的消息属于会话记录，改不了——这也是目前唯一能改的时机；
- 右侧删除图标仍然只是丢弃；
- pig 没有「原地编辑队列」的 RPC，所以实现是「取回 + 重发」。
