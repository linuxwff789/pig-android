## v1.1.71.47：点思考不会再展开工具卡

**问题**
搜索跳转是按「行」定位的。当命中 id 对不上、靠文字片段兜底时，工具组里的卡片会回退到第一张；而思考又可能被合进工具组，于是点了一条思考命中，展开的却是旁边某个工具卡。

**修复**
- 命中类型现在参与展开：
  - **思考命中**：只展开思考（包括工具组上方的 reasoning），不展开任何工具卡。
  - **工具命中**：才展开对应卡片。
  - **正文命中**：只滚动并高亮，不额外展开。
- 工具卡查找顺序：命中 id → 结果/参数里包含命中片段 → 仅当类型是工具时回退第一张。
- 片段兜底定位现在也会匹配工具组里的 reasoning，思考命中不会再定位到相邻行。
- 工具组上方思考的正文同样会高亮搜索词。

只装 APK 即可，relay 不需要更新。
