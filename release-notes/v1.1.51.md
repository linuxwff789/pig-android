## Compact pack 里给不同工具上色了

`chat.toolCard.byTool` 用主题 token 给常见工具分配颜色（同时作用于工具组表头）：

| 工具 | 颜色 |
| --- | --- |
| `bash` | 绿（`success`） |
| `edit` / `write` | 琥珀（`warning`） |
| `read` | 天蓝（`secondary`） |
| `webfetch` / `websearch` / `subagent` | 紫（`primary`） |
| `memory*` / `scratchpad` / `codegraph*` | 青（`tertiary`） |

没列到的工具保持卡片默认色。用的是 token 而不是写死色值，所以切换皮肤
（霓虹/深海/森林/纸白）时颜色会跟着主题走。

想改自己的配色，编辑 `~/.pig/android-ui/layout/chat.json`：

```json
"chat": {
  "toolCard": {
    "byTool": {
      "bash": { "iconTint": "success", "iconBackground": "success", "titleColor": "success" }
    }
  }
}
```

## 另外

- 工具组表头的标题也跟随 `byTool.titleColor`（之前只有图标变了）。
- 宽度上限仍可用：`"maxWidth": 420`（0 = 铺满）。

## 升级

1. 装 `app-release.apk`（1.1.51）；
2. Termux 里重跑安装命令（relay 1.1.51 的种子 pack 带上了这套配色）；
3. 重装前也可以直接改 `~/.pig/android-ui`，热更新立刻生效。
