## 从这个版本起，只发预览版

按你说的，之后的构建都是 **GitHub Pre-release（预览版）**，不再每次发正式版：

- release 列表里会标注 Pre-release，`latest` 只留给真正的稳定版；
- 安装脚本（`install-termux.sh`）现在自己找**最新的 release，包括预览版**，
  所以不用改地址也能装到最新构建；
- 文档里的一行命令改成直接取仓库里的脚本（不依赖某个 release 资产）：
  ```
  curl -fsSL https://raw.githubusercontent.com/linuxwff789/pig-android/main/scripts/install-termux.sh | sh
  ```
- App 的更新检查照旧（`releases.atom` 包含预览版），兜底接口也改成了会包含预览版的列表接口。

这个版本本身没有功能改动（上一版 1.1.63 修掉了删会话/切会话时那条 `pig exited: code=143` 的假报错）。

装 `app-release.apk` 即可；relay 无改动（1.1.63 之后没动过）。
