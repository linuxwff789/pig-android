## 新装后端不再把「没有模型」当成报错

刚装好的 `~/.pig` 是空的：没有 API key、没有自定义供应商、没有会话。pig 的
`get_available_models` 返回空列表，以前 App 会显示「无模型」，用户一发消息就得到
一条红色的 pig 错误，看起来像安装失败。

现在空后端被当作**配置向导**：

- 连接后如果没有任何可用模型，输入框上方出现一张卡片：
  「还没有可用模型」+ **添加供应商** + **备份 / 设置**（导出/导入）+ 关闭按钮。
  关掉后本次进程不再打扰；模型出现后卡片自动消失。
- 模型选择器里同样有 **添加供应商** 按钮（空列表时）。
- 没有模型时发送消息不会再打出红色错误，而是提示先去添加供应商或导入备份。
- 安装脚本结束时也会提示：`open Pig → 设置 → 模型供应商 to add a provider, or import a backup`。

内置 provider（OAuth / API key）仍然在 Termux 里用 `pig login` / `pig auth` 配置；
自定义端点用 App 原生的「模型供应商」页面。

## 升级

1. 装 `app-release.apk`（1.1.39）；
2. Termux 里重跑安装命令；
3. App → 设置 → 重启 relay。
